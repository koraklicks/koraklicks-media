# Kora Klicks newsroom: lessons learned

Every run reads this file before starting work and follows it. When a run hits a new problem,
it adds one line here (date · what happened · the rule from now on). The end-of-day review
cleans the list up and turns repeated lessons into rules in the skill/agent files.
Newest first.

## Open lessons

- **13 Oct 00:20 · The repo clone started on a detached HEAD, so `git pull --rebase` failed and the first push was rejected (non-fast-forward).** → If `git pull --rebase` says "not currently on a branch", run `git fetch origin main && git checkout -B main origin/main` and cherry-pick the log commit before pushing.

- **13 Oct 00:05 · Coventry–Newcastle / Levante–Sevilla FT: the `#fragment` trick no longer refreshed pages (FilGoal strip, So3ody, Korabia returned the same 90+5' snapshot for 10+ min; `?r=N` query strings did not help either); the Belgian broadcaster Sporza match page (sporza.be/nl/sport/voetbal/~ID, found by searching «sporza <home> <away>») showed «afgelopen» + all scorers right after the whistle.** → For EPL/LaLiga FT, search «sporza <home> <away>» early as the FT-status check, paired with the FilGoal/365Scores score; a late-goal match (stoppage-time equaliser) stays on HOLD until two sources agree.

- **12 Oct 23:51 · Torino–Udinese FT: all four approved services + Tuttosport/ToroNews/Sky stayed cached (pre-match to 2nd-half 46'); the English/Italian search «<home> <away> full time <scorer names>» returned Football Italia, Calciomercato/Goal and Virgilio «risultato finale» FT pages within ~5 min of the whistle, but none of these is on the Tier-1 list, so FilGoal's live 2-1 + several non-Tier-1 FT reports was used (as for Atalanta–Venezia).** → For Serie A FT, at the whistle search with the scorer names + «finale»/«full time» and pair with the FilGoal matches page; owner to decide whether Football Italia / Goal-Calciomercato count as a Tier-1 FT report for Serie A.

- **12 Oct 23:20 · القوة الجوية × العين (ACLE) FT: 365Scores/Sofascore/Yallakora fixtures stayed cached at HT/71' 15 min after FT, but the FilGoal homepage `filgoal.com/?top=true` with a new `#fragment` showed «انتهت» 1-4, and the Iraqi News Agency report (via Hathalyoum) came up for «القوة الجوية يخسر أمام العين».** → For ACLE FT, fetch the FilGoal homepage strip with a fresh `#fragment` first; pair it with the national news agency/AFC report.

- **12 Oct 23:12 · Al Nassr–Neftchi (ACLE) kick-off was delayed ~1 h (security alert in Riyadh) but the 23:05 FT task was planned from the original 21:15 KO; search «<home> <away> kickoff delayed» found it.** → FT/HT tasks first confirm the match actually kicked off on time (search the teams + "delayed"/«تأجيل») and re-arm themselves (send_later) for the new FT time instead of ending.
- **12 Oct 22:13 · Tractor–Al Shamal (ACLE) sat on HOLD for an hour: live-score pages cached, only Iranian outlets; the English search «<home> <away> AFC Champions League Elite» (extended mode) returned the official AFC match report «MD2: <home> 0-0 <away>» on the-afc.com.** → For any ACLE result, search the AFC report title format first; an AFC report is an official source (publish alone). Also: X rejects > 280 chars for this brand, so keep X copy ≤ 250.
- **12 Oct 22:07 · Smouha–Ghazl FT: at FT + 10 min FilGoal (match, league and home pages) and Yallakora (team fixtures) were cached pre-match and Arabic searches only returned old matches; the English search «365scores ar football match <home> <away>» returned the 365Scores and Sofascore match pages, both already «Final/FT» with scorer + assist.** → For Egyptian FT round-ups, run that English search at the whistle first (gives two approved services in one go); posts went out ~17 min after FT because the Arabic route was tried first.
- **12 Oct 22:00 · Pyramids–Ceramica FT: at the whistle FilGoal/Yallakora/Korabia pages still said live (4-1, 90+1') but the Sofascore match page opened with a `#id:...` fragment added to the search-returned URL bypassed the 15-min WebFetch cache and showed «Finished» 4-1; the same trick (`#x` on a search-returned FilGoal/Yallakora URL) re-fetches a page fresh.** → For FT, re-fetch the search-returned Sofascore match URL with a new `#fragment` every 2 min from FT − 5; pair it with the FilGoal/Yallakora score.
- **12 Oct 21:30 · Atalanta–Venezia FT: at FT + 5 min 365Scores/So3ody/FilGoal still said LIVE 90+3' (cached) and Sofascore/Fox/Virgilio/Bergamonews pages were pre-match; the Italian search «<home>-<away> 3-1 risultato finale» returned FT reports (trivenetogoal, MilanPress, LaViola) time-stamped ~1 min after the whistle.** → For Serie A FT, search in Italian «risultato finale» right at the whistle and pair it with the 365Scores/FilGoal score; Gazzetta/Corriere/Sky pages didn't show up in search within 10 min.
- **12 Oct 21:20 · ACLE الوصل × الأهلي FT: 365Scores match page froze at 90+1 showing 1-2 (and its summary template said «انتهت 1-1»); the real FT was 3-1 after a 90+2 goal in a 10-min stoppage. Al Riyadiyah/Sofascore/So3ody match pages stayed pre-match/HT.** → Never publish an FT from a page showing a live minute, even in stoppage time; for Saudi/ACLE FT search «الأهلي يهزم/يسقط/يفوز + الخصم» and «العين الإخبارية بث مباشر» + teams, and Kooora's team «مباريات» page (shows «انتهت» + score) — FT headlines appeared ~8 min after the whistle.
- **12 Oct 20:58 · Pyramids–Ceramica HT: WebFetch rejects Egypt Telegraph/Yallakora article URLs as too long and short forms (`/article/ID`, `/news/ID`) as "permission not answered"; the search query «بوابة الأهرام <teams> نهاية الشوط الأول» found the Ahram HT report (20:54) and the FilGoal team page `filgoal.com/teams/ID` showed the live score.** → For Egyptian HT/FT go straight to that Ahram search + the FilGoal team page from search results; a Metricool 502 can mean nothing was created: check getScheduledPosts before one retry.
- **12 Oct 19:58 · ACLE الوصل × الأهلي HT not posted: at HT only so3ody/korabia match pages (same feed, ID 2147279894) showed «استراحه» 1-1; Sofascore, Yallakora, Kooora, Al Riyadiyah and AiScore pages were cached pre-match/0-0, 365Scores/ESPN wouldn't load.** → For ACLE/Saudi HT, start searching at HT − 5 min with «الشوط الأول» + teams; so3ody/korabia count as ONE source (not on the approved list). Owner to decide whether So3ody/Korabia can count as an approved live-score service for Saudi/ACLE games.
- **12 Oct 19:20 · EGY 17:00 FT round-up: 365Scores team page and Korabia/so3ody match pages stayed frozen at 81'–82' (المقاولون 1-0 زد) for 30+ min; the real FT was 1-1 (89' equaliser). Publishing from the snapshot would have been wrong.** → Never treat a live-page score as FT unless the page says «انتهت»/FT; for Egyptian FT use the today-strip on any filgoal.com/articles/N page returned by search (shows «انتهت» + score) plus a Yallakora FT headline from search results.
- **12 Oct 18:45 · WebFetch on typed URLs (filgoal.com/matches, yallakora match-center, sofascore team page, espn) failed with "permission request not answered" even though the domains are allowed; URLs copied from a WebSearch result opened fine. Sofascore/365Scores/FotMob/ysscores pages returned via search were cached pre-match ~15 min after FT.** → In unattended runs, open match pages only from URLs that a WebSearch returned (search «<teams> نتيجة» / site name + teams); for ACLE/Saudi games Al Riyadiyah `matches.arriyadiyah.com` (Tier 1) and So3ody match pages update live. Also: `already_posted.sh` flags CHECK lines containing "posted" as POSTED — read the matched line before trusting it.
- **12 Oct 18:35 · Line-ups for الوصل × الأهلي السعودي: Sofascore/365Scores line-up tabs were empty or blocked (WebFetch only opens URLs that came from a search result; Yallakora match URLs are too long), so no live-score service showed the XIs.** → For Saudi clubs, use Al Riyadiyah's match centre (search «نتيجة مباراة X و Y arriyadiyah» → matches.arriyadiyah.com/matches/ID, Tier 1) for line-ups, plus one more outlet with the same XI; fetch only URLs returned by WebSearch.
- **12 Oct 15:27 · The owner posted on the Facebook page by hand and it worked, so the page itself is not restricted; the block is on posting through Metricool (the app).** → Facebook FEED is un-paused: try ONE feed post for the next big result tonight (Pyramids or Al Nassr). If it fails again with error 400, stop feed/reels and tell the owner to reconnect Facebook inside Metricool. Stories continue as normal.
- **12 Oct · The 08:47 match planner stalled ~6 h; today's live tasks were created only at 15:15.** → Every newsroom run from 12:00 checks that today's log has a "Live-coverage plan"; if not, it builds the plan itself (fixtures from FilGoal/Yallakora, create the one-off tasks) before anything else.
- **12 Oct · FilGoal/Yallakora still timed out after the site permissions were added, because runs don't start inside the repo.** → Run `bash scripts/setup_session.sh` first in every run.
- **12 Oct · Facebook FEED and REELS still fail with error 400 after 10+ h; Stories work.** → Feed/Reels paused until the owner checks the page in Meta Business Suite; keep posting Facebook Stories.
- **12 Oct 15:20 · The live-match planner fired at 08:47 but its session stalled ~6 h after creating the first task (rest created 15:20).** Nothing was missed today because the first kick-off planned was 17:00, but a noon/afternoon match would have lost its line-ups. → Planner: create all match tasks in one batch right after fixtures are confirmed, before writing the log; if a planner run starts after 12:00, skip any slot already past and say so in the log.
- **12 Oct 12:59 · Metricool rejected a TikTok video post: "TikTok title is required".** → Always set `tiktokData.title` (short Arabic line) on TikTok video posts. Also: write «الأهلي السعودي» (not «الأهلي») for Al Ahli Saudi on cards/captions.
- **12 Oct · YouTube roundup: in render.py (theme major) a `list` with 4–5 items or a `table` with 5 rows runs into the bottom source line; an older note had Alavés–Atlético as 2-1 (it was 1-2).** → Max 3 items per list and 4 table rows in the long video (split extra results into `result` scenes); re-check every score from a source before reusing it from logs.
- **12 Oct 09:46 · Facebook FEED still blocked (ERROR 400 rate limit) after ~10 h with no feed attempt and 0 feed posts today; Stories keep working.** The block is longer than the 2 h back-off assumes. → Stop Facebook FEED/REEL tries until the owner checks the page in Meta Business Suite (Page quality / restrictions); until then Facebook gets Stories only. Also: story_short.py card lines in the Cairo font show digits/Latin in serif — write numbers and source names in Arabic words on cards.
- **12 Oct 01:15 · Three 11 Oct results (Racing 2-2 Valencia, Al Shabab 3-0 Al Taawoun, Elche 0-0 Celta) sat on HOLD for 4–7 h: wide agreement from EFE and Saudi dailies (Sabq, Al Yaum, Al Jazirah) but only one approved source; WebSearch with `allowed_domains` (4+ sports domains) was rejected by the proxy (HTTP 400).** → Don't use `allowed_domains` for sports sites; search with the site name in the query. **Owner decided 12 Oct:** one Tier-1 FT report + one of the four live-score services is enough (see trusted-sources).
- **12 Oct review · Como 0-0 Roma (17:15 and 00:20) and Crystal Palace 3-1 Forest (18:36 and 23:20) were each published twice, and the Zamalek–Ahly line-ups went out twice on X (20:02, 20:20).** A run trusted an earlier "not yet posted" note and checked Metricool only for the last few hours. → Firm rule now in `run-newsroom` step 3 and `live-match` step 3: run `scripts/already_posted.sh <teams>` and check `getScheduledPosts` from 00:00 today before every post.
- **12 Oct review · Facebook feed: 5 posts in 88 min in the morning, then every feed post and reel failed for 9 hours, so Zamalek 0-2 Ahly and Liverpool 0-3 City never reached the feed. Stories always worked.** → Firm rule now in `references/metricool.md`: ≥ 60 min between feed posts, max 2 in any 3 h, big results as a Facebook Story right away.
- **12 Oct review · Half-time was late or missing on both big matches (Liverpool–City HT never posted; Zamalek–Ahly HT 15 min late) because live pages were cached.** → `live-match` step 3: HT within 5 min; if live pages are cached, use a searched HT report (Ahram gate for Egypt, Sky/BBC report pages for England).
- **12 Oct review · Saturday's Alavés 2-1 Atlético was never posted; the morning catch-up took only 3 Saturday games.** → `boss.md`: the morning run covers every Tier A result of the previous evening that is not in the log.
- **12 Oct review · Posts made by the line-ups task (20:20–20:21) and a manual Palmer post (morning) are not in the log.** → Every task and the owner session log every post with its plannerUrl; the review counts from Metricool, not only the log.
- **11 Oct · Line-up tasks started 5 min before kick-off (Liverpool XI 5 min after kick-off, Zamalek–Ahly XIs posted by the owner by hand).** Happened twice in one day → now firm: the match planner creates line-up tasks at kick-off − 45 min (planner prompt updated 11 Oct 16:43) and `live-match` step 3 says post text on X first if late.
- **11 Oct · music.py failed on a missing `soundfile` module.** Run `pip install soundfile --break-system-packages` if music.py fails.

## Became rules (removed from this list on 12 Oct)
- Speed rule for match data (two of Sofascore/365Scores/FilGoal/Yallakora), big results alone within 10 min, no waiting for BBC/Sky → `newsroom-rules` SKILL.md.
- Facebook rate limit → `references/metricool.md`.
- Fonts, base64 `@font-face`, Lalezar on every Arabic line, RTL score order, home × away order, look before hosting → `agents/creative.md`.
- Source reading tips (search first, cached live pages, FilGoal date, Ahram gate, Sky/club reports, long URLs, unsupported numbers like «القمة N») → `references/trusted-sources.md`.
- Story with 5 matches overflowing → fixed in `story_short.py` (compact list for 4–5 items).
