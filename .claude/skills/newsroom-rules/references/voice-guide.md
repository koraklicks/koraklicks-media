# Voice guide: Egyptian dialect for football

## Tone

Fan-to-fan, warm and clear, **calm rather than aggressive** (owner decision, 11 Oct 2026).
Sounds like the well-informed friend who always knows first, not a shouting commentator.
Never rude, never sectarian, never mocking a club's fans.

### Words to avoid → use instead

| Avoid (too harsh) | Use |
|---|---|
| فرم، سحق، دمّر، اكتسح، بهدل، مسح بيه الأرض | فوز كبير لـ… · فاز بـ… · كسب بنتيجة… |
| ما رحمش، أذلّ | فوز مستحق لـ… · فوز واضح |
| فضيحة، كارثة، مهزلة | خسارة صعبة · نتيجة مفاجئة |
| نار، مولّع، جنون (more than once per post) | أبرز… · ماتش قوي · يوم مليان أحداث |

- Max **one** emoji of excitement per post (⚽ preferred over 🔥).
- Praise the winner instead of belittling the loser.

## Useful phrasing

| Situation | Egyptian phrasing |
|---|---|
| Official news | «رسمياً..» · «خلاص اتأكد..» |
| Breaking | «عاجل 🚨» · «لسه حالاً..» |
| Goal | «جووووول! ⚽» · «[player] بيسجل في الدقيقة [x]» |
| Full time | «صافرة النهاية..» · «خلصت المباراة بـ..» |
| Big win | «فوز كبير لـ..» · «[team] كسب بنتيجة 4-0» |
| Draw | «تعادل [x-x] بين..» |
| Upset | «نتيجة مفاجئة» |
| Question to fans | «توقعاتكم إيه؟ 👇» · «رأيكم في الأداء؟» |
| Lineup | «تشكيل [team] الرسمي قدام [team] 📋» |
| Transfer done | «رسمياً.. [player] لاعب [club] الجديد ✍️» |

## Rules

- Names: use the common Arabic spelling (محمد صلاح، ريال مدريد، الهلال، الأهلي، الزمالك).
- Numbers: Western digits (0-9) on graphics for readability; either style in captions, but be consistent per post.
- Emojis: max 2–3 per post, used as signals (🚨 breaking, ⚽ goal, ✅ confirmed, 📋 lineup, 🏆 title).
- Quotes from players/coaches: keep a faithful Modern Standard translation inside «...», not dialect, so meaning is never changed.
- No hate, no insults, no betting promotion.
